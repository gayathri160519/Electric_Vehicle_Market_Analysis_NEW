## 📊 Project Overview
This project analyzes Electric Vehicle (EV) registration data to understand EV adoption trends, manufacturer performance, vehicle types, electric range distribution, and geographical distribution across counties. The objective is to transform raw EV data into meaningful insights through data cleaning, exploratory data analysis (EDA), and interactive Power BI dashboards.

## 🗂️ Data Source

Dataset: Electric Vehicle Market Analysis

Source: Government Portals

Dataset Size

Records: 5000
Features: 16 Columns
Key Variables:

- Electric Vehicle Type
- Electric Range

## 💡 Key Insights

Battery Electric Vehicles (BEVs) dominate the EV market compared to Plug-in Hybrid Electric Vehicles (PHEVs).
Tesla is the leading manufacturer with the highest number of registered EVs.
Electric vehicle adoption has increased significantly in recent years.
Certain counties show higher EV concentration than others.
Vehicles with greater electric range are becoming increasingly common.
CAFV-eligible vehicles represent a large share of the dataset.

## 🚀 Recommendations

Expand charging infrastructure in high-growth counties.
Promote EV adoption in low-registration regions through incentives.
Encourage manufacturers to increase vehicle range.
Support CAFV-eligible vehicle programs to accelerate clean-energy adoption.
Monitor county-level adoption trends for targeted policymaking.
